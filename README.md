# ⚡ Tributo a Nikola Tesla

## 🚀 Sobre o Projeto
Página de tributo desenvolvida para consolidar os fundamentos estruturais de desenvolvimento web. O foco principal deste projeto foi a aplicação de **HTML5 Semântico** e a construção de um layout responsivo inicial com **CSS3**.

🔗 **[Acesse a página em Produção aqui](https://eliesdrasdias.github.io/tributo-nikola-tesla/)**

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de conteúdo.
* **CSS3:** Estilização base.
